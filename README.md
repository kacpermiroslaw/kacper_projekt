Projekt: Wypożyczalnia rowerów 🚲
Opis projektu:

Program do obsługi wypożyczalni rowerów, który umożliwia sprawdzanie dostępnych rowerów, ich wypożyczanie oraz przyjmowanie zwrotów.

Funkcje programu:
Lista rowerów – wyświetlanie dostępnych rowerów i ich modeli.

Informacje o rowerach – nazwa, model, cena i dostępność.

Wypożyczenie roweru – zapisanie danych klienta i wybranego roweru.

Zwrot roweru – oznaczenie roweru jako zwróconego.

Koszt wypożyczenia – obliczanie ceny za czas wypożyczenia.
